# App de SONORIA FM para Android (con Android Auto)

## Subir el proyecto a GitHub
1. Entra en tu repositorio `sonoriafm-android` en github.com y pulsa **uploading an existing file**.
2. Descomprime este ZIP y arrastra TODO el contenido de la carpeta a la página (incluidas las carpetas `app` y `.github`).
3. Pulsa **Commit changes**.
   - Si la carpeta `.github` no se sube: **Add file > Create new file**, escribe como nombre `.github/workflows/android.yml` y pega el contenido del archivo `android-workflow.txt` del ZIP. Pulsa **Commit changes**.
4. Pestaña **Actions**: espera al tic verde (~5 min). Si sale una cruz roja, hazme una captura.
